# Mockups

Exported from the Claude design canvas (https://claude.ai/artifact/Q4BD2E2SwK5GsMDGY9Xi4P).
Each file is one self-contained "Design Component": markup + CSS in <helmet>, behavior in the
<script type="text/x-dc"> block (`renderVals()` returns the values used by `{{holes}}`;
`<sc-for>` repeats, `<sc-if>` branches). They need the canvas runtime to run, so read them as
a precise reference rather than opening them directly.

- HomeMosque.dc.html  — home (final)
- WritingWall.dc.html — writing wall + reader (final)
- ProjExplode.dc.html — projects: exploded view + long-form posts (final direction)
- CreativeV2.dc.html  — creative: clothesline + composer (polish)
- Timeline.dc.html    — timeline, T2: one sentence that rewrites itself (final)

Images: /_blob/<id> → pics/ files (see SPEC.md appendix).
