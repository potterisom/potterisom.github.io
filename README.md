# potterisom.github.io

Leyla Salken's personal site. Built with [Astro](https://astro.build), deployed to GitHub Pages.

```
npm install
npm run dev        # http://localhost:4321
npm run build      # writes dist/
npm run shots      # Playwright checks + screenshots at 1440 and 390 (after a build)
```

- `handoff/SPEC.md` — the design spec; `handoff/mockups/` — the reference designs.
- `src/pages/` pages, `src/scripts/` interactions, `src/styles/tokens.css` design tokens.
- `src/assets/pics/` photos (the build makes AVIF/WebP), `public/docs/` PDFs.
- `archive/` — the previous site, kept but not published.
